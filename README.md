# LongTV

LongTV is a private media box app built as a personal learning project for Jetpack Compose.

The project is maintained for personal use and experimentation. It was developed with help from AI tools while learning Android app architecture, Compose UI patterns, TV-friendly navigation, and media playback integration.

This repository is not intended as a public streaming service, content distribution platform, or commercial product.

## Purpose

- Learn Jetpack Compose through a real Android TV and phone app.
- Explore adaptive UI patterns for remote control and touch interaction.
- Experiment with media playback, local configuration, favorites, history, and search flows.
- Keep a private, self-use media box implementation for study and personal practice.

## Notes

LongTV is provided as-is for private learning and personal use. Any configuration, source, or media access used with the app should comply with applicable laws and the user's own rights and permissions.
